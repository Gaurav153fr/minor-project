4. (a) How does a DPDA differ from NPDA?
   - **Answer**: A Deterministic Pushdown Automaton (DPDA) differs from a Non-Deterministic Pushdown Automaton (NPDA) in that a DPDA has deterministic transitions, meaning that for each state and input symbol, there is exactly one transition possible. In contrast, an NPDA allows for multiple transitions from a single state on a single input symbol.

4. (b) Design a TM to accept the language:
   ```
   L = {0^n 1^n / n ≥ 1}
   ```
   - **Answer**: The Turing Machine (TM) for this language would have states to count the number of 0's and 1's separately and ensure they are equal before accepting the string.

4. (c) Explain Post Correspondence Problem.
   - **Answer**: The Post Correspondence Problem (PCP) is a decision problem where we are given two sequences of strings, and we need to find a sequence of indices such that the concatenation of the corresponding strings from both sequences forms a palindrome.

4. (d) Design a PDA that accepts:
   ```
   {w ⊂ w^R / w in (0+1)^*}
   ```
   - **Answer**: The PDA would push symbols onto the stack and pop them off in reverse order, ensuring that the stack is empty when the input is accepted.

#### Section 5:
5. (a) Define Partial and Total Functions.
   - **Answer**: A partial function is a function that is defined only for some inputs in its domain. A total function is a function that is defined for every input in its domain.

5. (b) Explain Recursive and Recursively Enumerable Sets.
   - **Answer**: A recursively enumerable set is a set whose elements can be generated by a Turing machine that halts on all inputs. A recursive set is a recursively enumerable set that is also decidable, meaning there exists a Turing machine that halts on all inputs and correctly decides whether each input belongs to the set.

5. (c) Explain Turing Model for Computation.
   - **Answer**: The Turing model of computation is based on a hypothetical device called a Turing machine, which consists of a tape divided into cells, a read/write head that can move along the tape, and a control unit that determines the machine's behavior based on the current state and the symbol under the read/write head.

5. (d) What are Primitive Recursive Functions? Show that the function f(x, y) = x + y is primitive recursive.
   - **Answer**: Primitive recursive functions are functions that can be constructed using basic operations like projection functions, composition, and primitive recursion. The function f(x, y) = x + y can be expressed as a primitive recursive function using the addition operation defined recursively as follows:
     ```
     add(0, y) = y,
     add(succ(x), y) = succ(add(x, y)).
     ```
     This shows that addition is a primitive recursive function.
